# 📘 JavaScript Beginner Programs (100 Easy Programs)

This repository contains **100 easy JavaScript program ideas** designed especially for **beginners** who are just starting their JavaScript journey.

The programs focus on **basic concepts only**, such as variables, loops, conditions, functions, arrays, and strings.

---

## 🎯 Purpose of This Repository

- Help beginners practice JavaScript fundamentals
- Build logical thinking step-by-step
- Prepare for basic interviews
- Improve confidence in writing simple programs

---

- Basic Input / Output
- Variables & Data Types
- If–Else Conditions
- Loops (for / while)
- Functions
- Arrays
- Strings
- Simple Math & Logic Programs
- Beginner Mini Projects
